# internal

Tempat untuk kode aplikasi yang tidak diekspos sebagai module publik. 
Direkomendasikan untuk menaruh implementasi Clean Architecture di sini (mis. adapters, repositories, usecases).

Saat ini proyek menggunakan struktur domain/usecase/infrastructure/interface yang setara dengan pendekatan internal. 
Folder ini disediakan untuk ekspansi ke depan tanpa memindahkan kode yang sudah ada.
